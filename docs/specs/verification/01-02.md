# Fact-check ledger — specs 01 (data ingest) and 02 (outage model)

Independent fact-check, 2026-09-05. Every load-bearing claim was checked against a primary
source (live HTTP, sample downloads, library introspection in the repo `.venv`, or the
publisher's own page). Verdicts: **VERIFIED** (claim stands, source given), **CORRECTED**
(spec text changed in place; old → new recorded), **UNVERIFIABLE** (tagged `[UNVERIFIED]` in
the spec with what would verify it). Scratch downloads lived under the session scratchpad and
were not committed. No secrets were involved.

Tools: `curl -sIL` / `curl -r` range requests, `uv run python` (pandas, pyarrow, pyogrio,
duckdb 1.5.5, lightgbm 4.7.0, pandapower 3.5.3, herbie 2026.3.0, matpower 8.1.0.2.3.0),
figshare / ScienceBase / ArcGIS REST / Opendatasoft JSON APIs, doi.org resolution, WebSearch
for NHC landfall facts and SPP/MISO membership.
