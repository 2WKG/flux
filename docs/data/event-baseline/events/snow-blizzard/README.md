# Snow and blizzard candidate coverage

This bundle records five independent Upper Midwest candidate episodes: April
2018, February 2019, December 2021, and two distinct December 2022 systems.
NCEI Storm Events provides county-named forecast-zone weather evidence with
native event IDs and explicit local-standard-time to UTC conversions.

All five records remain `candidate_only`. A prior bounded EAGLE-I range method
cannot prove complete coverage because the annual source is not globally
time-ordered. Its apparent samples are therefore not used as outage evidence.
Each record is `UncoveredLabel`, has no outage rate, and has no five-percent
positive/negative assertion until the shared exhaustive annual scan creates a
valid county-window receipt.

The candidate frame is the listed event systems, selected from NWS Twin Cities
event summaries and NCEI Storm Events records. It is not a prevalence or
statistical-sufficiency sample.
