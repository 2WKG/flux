# Minnesota aggregate-mode readiness receipt

**Selected model mode: `aggregate`.** The Minnesota topology decision gate in
[`docs/specs/10-minnesota-demo.md`](../specs/10-minnesota-demo.md) has five
required items and this repository satisfies none of them. Aggregate mode is
therefore the honest selection, and Texas/ACTIVSg2000 topology is not a
substitute for any of them.

The machine-readable form of everything below is
[`data/artifacts/minnesota/readiness-receipt-v1.json`](../../data/artifacts/minnesota/readiness-receipt-v1.json),
regenerated by:

```powershell
uv run --extra dev python -m pipelines.minnesota_readiness `
  --report data/artifacts/minnesota/readiness-receipt-v1.json
```

Add `--database data/duck/grid.duckdb` to replace the county-grain
`unavailable` status below with measured counts. Every number in this document
came from a query the receipt ran and publishes; the SQL is quoted here and in
the JSON.

## What this receipt is not

It is not an ingest pipeline, a rebuild, or a promotion. It reads evidence that
is already committed, re-measures it, and records a decision. The county-grain
Minnesota load is separate, already-published work — see
[`minnesota-p0-curated-source-receipts.md`](./minnesota-p0-curated-source-receipts.md)
(PR #266) — and this receipt cites it rather than recreating it.

## 3. Aggregate output

### Named regional stress metric

**`mn_agg_miso_demand_stress_index_v1` — MISO balancing-authority demand stress
index.**

- **Formula:** `S(t) = D_MISO(t) / max_τ D_MISO(τ)` over the manifest window.
- **Units:** dimensionless ratio in (0, 1]; the inputs `D_MISO(t)` and the
  window peak are megawatts (MW).
- **Reporting unit:** MISO balancing authority, hourly, UTC end of hour. That
  is the smallest unit the source supports.
- **Allocation assumptions:** **none applied.** The manifest records
  `allocation_status: unavailable`, so no MISO value is allocated to a
  Minnesota county, utility, zone, or bus. County plant capacity is reported
  separately at county grain and is never used as an allocation weight for
  demand.
- **Source/synthetic label:** `source_backed` — EIA-930 Balance, MISO, 2024 H1.
  No synthetic, modelled, imputed, or interpolated value contributes.
- **Limitations:** MISO spans fifteen states and Manitoba. `S(t)` is a
  MISO-wide stress shape, not Minnesota demand and not a Minnesota load. The
  denominator is the peak inside the committed window only; a different window
  gives a different denominator.

### Measured values

```sql
-- mn_agg_miso_demand_stress_index_v1
WITH hourly AS (
    SELECT "UTC Time at End of Hour" AS ts, "Demand (MW)" AS demand_mw
    FROM read_csv_auto('pipelines/fixtures/inputs/miso_ba_context_2024_h1.csv',
                       header = true)
    WHERE "Demand (MW)" IS NOT NULL
), peak AS (SELECT max(demand_mw) AS peak_mw FROM hourly)
SELECT (SELECT peak_mw FROM peak) AS window_peak_demand_mw,
       (SELECT ts FROM hourly ORDER BY demand_mw DESC, ts LIMIT 1)
           AS window_peak_hour_utc,
       round(min(demand_mw) / (SELECT peak_mw FROM peak), 6) AS min_index,
       round(avg(demand_mw) / (SELECT peak_mw FROM peak), 6) AS mean_index,
       round(quantile_cont(demand_mw, 0.95)
             / (SELECT peak_mw FROM peak), 6) AS p95_index,
       count(*) AS scored_hours
FROM hourly;
```

## 4. Prohibited claims in aggregate mode

The receipt emits this list in its JSON, so a consumer that reads only the
machine-readable form still sees it. While the selected mode is `aggregate`,
this artifact and anything derived from it **must not** emit or imply:

1. bus or branch **power flow** (MW, MVA, Mvar, or per-unit);
2. **line thermal rating**, `rate_a`, ampacity, or **line loading** percent;
3. **DC power flow** or any solved network result;
4. **N-1** or any contingency-screening conclusion;
5. breaker or line **trip**;
6. **cascade** or outage propagation;
7. **outage replay** or observed-outage attribution;
8. **interconnection study**, deliverability, or transfer capability;
9. congestion, marginal loss, or locational price.

This path is a *Minnesota aggregate stress model*, not a grid twin.
